# CodeMentorAI Backend

Python + FastAPI backend for CodeMentorAI.

## Installation

```bash
pip install -r requirements.txt
```

## Running the Backend

```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Or run directly:

```bash
python app/main.py
```

## API Documentation

Once running, visit:
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc
